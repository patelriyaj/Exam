Steps to publish this web application online

Step 1: Save HTML File

Save this complete code file onto your computer as index.html.

Step 2: Create GitHub Repository
  1. Log into GitHub and create a new repository (e.g. dbatu-sem7-tracker).
  2. Upload your index.html file to the repository.
Step 3: Enable Pages
  1. Go to Repository Settings → Pages.
  2. Under Build and deployment, set Source to Deploy from a branch.
  3. Select main branch and click Save.
  4. Your site will be live at https://yourusername.github.io/dbatu-sem7-tracker!
